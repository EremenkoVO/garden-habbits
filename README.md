# Сад привычек

Android-приложение на Flutter для ежедневного отслеживания привычек. Все данные
хранятся локально в SQLite и не требуют аккаунта или интернета.

## Возможности

- создание, редактирование и удаление привычек;
- необязательная дата окончания и до восьми времён напоминания в день;
- отметка выполнения за текущий день;
- переключение по дням и восстановление пропущенных отметок;
- GitHub-подобная карта активности за 12 недель;
- текущая и лучшая серии, суммарные выполнения и достижения;
- локальные уведомления и обновление их расписания через Android WorkManager.

## Запуск

Требуется Flutter 3.38.1+ и Android SDK 36.

```bash
flutter pub get
flutter test
flutter run
```

## Архитектура

- `lib/domain` — модели и расчёт серий/достижений;
- `lib/data` — SQLite-схема и репозиторий;
- `lib/services` — уведомления и фоновая задача;
- `lib/ui` — Material 3 интерфейс и тепловая карта;
- `test` — тесты бизнес-логики.

Каждой привычке можно задать несколько независимых времён (например, для приёма
лекарств утром, днём и вечером). Напоминания создаются на ближайшие 30 дней в
пределах периода привычки.
WorkManager ежедневно обновляет окно, а после перезагрузки Android восстанавливает
запланированные уведомления.

Если привычка уже отмечена выполненной сегодня, оставшиеся уведомления за этот
день отменяются. Фоновое обновление также не планирует уведомления на даты, для
которых уже есть отметка.
